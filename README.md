# FinCalc Pro

**FinCalc Pro** - это современное настольное приложение для Windows/Linux на Python, предназначенное для автоматизации расчётов переводов, гонораров, комиссий и ведения истории финансовых операций. Поддерживаются различные способы оплаты (карта РФ, ИП, евро), автоматический или ручной ввод курса валют, расчёт зарплаты менеджера и статистика по периодам.

## Основные возможности

- Удобный интерфейс на базе Tkinter с современной светлой темой (sv_ttk)
- Три типа операций:
    - 💳 Карта РФ
    - 🏢 ИП
    - 🇪🇺 Евро-счет
- Автоматическое получение курса EUR/RUB (с fallback на ручной ввод)
- Учёт возвратов, комиссий, налогов, инвойсов
- Ведение истории всех операций с возможностью удаления и отмены удаления
- Подробная статистика за любой выбранный период
- Сохранение истории в `history.json` (в каталоге приложения)
- Быстрый просмотр деталей каждой операции

## Быстрый старт

### Запуск из исходников

1. Установите Python 3.8+.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```    

Минимальные зависимости:
- `tkinter`
- `sv_ttk`
- `requests`
- `python-dateutil`
- `beautifulsoup4`

- Запустите:
```bash
python main.py
```

### Сборка standalone .exe

Экспорт в standalone .exe (без необходимости установки Python) осуществляется посредством `setup_wine_env.sh` и `build_exe.sh`
Готовый исполняемый файл будет находиться в папке `dist/`.

> **Примечание:**  
> В папке с .exe должен находиться файл `history.json` (создаётся автоматически при первом запуске).

## Структура проекта

```text
├── main.py           # Главный файл приложения 
├── setup_wine_env.sh # Создание wine-среды для сборки .exe
├── build_exe.sh # Сборка .exe
├── requirements.txt  # Список зависимостей 
├── history.json      # История операций (автоматически создаётся) 
└── README.md         # Документация
```
## Использование

1. Введите номер заказа.
2. Выберите способ оплаты.
3. Нажмите "Рассчитать" и заполните необходимые поля по подсказкам.
4. Итоговые суммы и детали будут сохранены в истории.
5. Для просмотра статистики за период используйте соответствующую кнопку.
6. Историю можно очищать, удалять отдельные записи и отменять удаление.

## Особенности реализации

- **Tkinter + ttk:** Кроссплатформенный GUI, поддержка современных тем оформления.
- **sv_ttk:** Современный внешний вид для стандартных виджетов.
- **BeautifulSoup:** Для парсинга курса EUR/RUB с сайта x-rates.com.
- **JSON:** Хранение истории операций.
- **PyInstaller:** Сборка .exe без необходимости установки Python на целевом компьютере
